# Pausa & Grão

Site fictício de uma cafeteria no Itaipu Multicenter (Niterói), feito em HTML, CSS e JavaScript puros, sem dependências.

- `index.html`, `style.css`, `script.js`: o site inteiro.
- Fontes: Playfair Display, Raleway e Caveat (Google Fonts).
- Fotos: [Unsplash](https://unsplash.com), carregadas direto do site delas.
- Base de design: [uiuxlabz/coffee-shop-html-template](https://github.com/uiuxlabz/coffee-shop-html-template) (uso livre) e inspiração no site do Ginger & White.

Os textos entre colchetes (piso, loja, horários) e o número de WhatsApp são placeholders. O horário usado no selo "Aberto agora" é de demonstração e fica no topo do `script.js` (`HOURS`).

Para rodar localmente, abra o `index.html` no navegador.
